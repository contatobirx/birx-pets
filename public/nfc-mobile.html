MODO CELULAR

Gravar BIRX ID no NFC

Leia o QR Code da mesma BIRX ID e grave o link diretamente na tag NFC usando um Android com Chrome.

Pronto para começar.
BIRX ID SELECIONADA

Use a mesma peça cujo QR Code acabou de ser lido. Encoste o celular na tag e mantenha até aparecer a confirmação.

Importante

Este modo grava o link NDEF para manter a produção andando. Ele não aplica a senha PWD/PACK usada pela gravadora PN5180. Para tags novas isso funciona normalmente; tags já protegidas podem recusar a gravação.
