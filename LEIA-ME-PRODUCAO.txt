BIRX PETS — SPRINT 2.6.1 / MÓDULO DE PRODUÇÃO

O que foi implementado
- Nova página: /producao.html
- Seleção de lote usando os dados reais do banco D1
- Resumo do lote: total, NFC/QR, estoque e ativadas
- PDF A4 de adesivos redondos de 30 mm
- QR Code branco sobre fundo preto, com texto SCAN
- Pequena sangria preta para recorte kiss cut
- Opção de mostrar ou esconder o código da tag no adesivo
- CSV de conferência com código, lote, modelo, status e link
- Atalho para Produção na página Preparação de Tags
- O gerador antigo não é mais carregado pela página admin-tags.html

Arquivos novos
- public/producao.html
- public/css/producao.css
- public/js/producao.js
- functions/api/producao/_shared.js
- functions/api/producao/lotes.js
- functions/api/producao/adesivos.js
- functions/api/producao/conferencia.js

Arquivo alterado
- public/admin-tags.html

Como publicar
1. Copie o conteúdo deste projeto para a pasta do seu repositório.
2. Dentro da pasta birx-pets, execute:

   npm install
   git add .
   git commit -m "feat: modulo de producao e exportacao de adesivos"
   git push origin main

3. Aguarde o deploy do Cloudflare Pages.
4. Acesse /producao.html.

Observação sobre validação
- Os novos arquivos passaram na verificação de sintaxe do Node.
- A criação de PDF com jsPDF e QR Code foi validada localmente.
- A suíte existente possui 1 teste antigo que já espera QR individual em 600x600,
  enquanto o projeto recebido usa 900x900 em public/js/admin-tags-qr.js.
  Essa divergência não foi criada pelo módulo de Produção.
