# Identidade visual

- A logo oficial da BIRX Pets é sempre `/assets/login.png` (arquivo `public/assets/login.png`).
- Use essa imagem em toda tela ou componente que exiba a marca BIRX Pets.
- Não crie nem use logos alternativas sem uma solicitação explícita do proprietário do projeto.

# Linguagem conforme o sexo do pet

- Em textos dinâmicos sobre um pet, respeite sempre o sexo cadastrado.
- Para fêmeas, use formas femininas como `protegida`, `perdida`, `desaparecida`, `encontrada` e `segura`.
- Para machos ou quando o sexo não estiver informado, use a forma masculina padrão.
